Контрольные вопросы по CSS

1. Для чего применяется технология CSS?

CSS (Cascading Style Sheets) используется для оформления внешнего вида веб-страниц. CSS позволяет задавать цвета, шрифты, расположение элементов, отступы и другие параметры отображения. Это нужно, чтобы отделить содержание (HTML) от оформления (CSS), что упрощает изменение дизайна и делает сайты более гибкими.

2. Почему используется термин «Каскадные» при определении таблиц стилей?

Слово «Каскадные» означает, что стили могут накладываться друг на друга и комбинироваться. Есть несколько уровней правил: стили браузера, внешние стили, внутренние стили и inline-стили. Если разные правила конфликтуют, применяется то, которое имеет более высокий приоритет, как в каскаде водопада.

3. К каким элементам могут быть привязаны стили?

Стили можно привязывать к:

  • HTML-тегам (например, ко всем <p>)
  • Классам (class="example")
  • ID элементам (id="header")
  • Группам элементов
  • Состояниям элементов (например, ссылка при наведении)

4. Какие правила приоритетности в применении CSS вам известны?

Приоритеты CSS (от самого важного к менее важному):

  1. Стиль с !important
  2. Inline-стили в теге
  3. Стили по ID
  4. Стили по классу
  5. Стили по тегу
  6. Стили браузера по умолчанию

5. Какие свойства используются для указания формы и оформления блоков?

Основные свойства для блоков:

  • width и height — ширина и высота
  • margin и padding — отступы снаружи и внутри
  • border — граница
  • background — фон
  • display — как отображается блок
  • position — позиционирование
  • float — обтекание
